ROLE

Act as a Senior Backend Architect, Python Developer, FastAPI Developer, MongoDB Developer, API Designer and Gemini API Developer.

Build a complete, functional and well-structured backend for a web application called:

"AI Smart Knowledge Management System"

The application is an interactive AI knowledge and learning assistant inspired by Google AI Studio and NotebookLM.

The main purpose of the application is to allow users to create notebooks, upload learning resources, communicate with their resources through an AI chatbot, and generate useful learning content such as summaries, quizzes, FAQs, flashcards and study notes.

IMPORTANT PROJECT SCOPE

This is a B.Tech Minor Project.

Keep the architecture SIMPLE, understandable, maintainable and easy to demonstrate in a viva.

DO NOT use:

- LangChain
- LlamaIndex
- RAG
- Vector databases
- Embeddings
- Pinecone
- Qdrant
- Milvus
- Weaviate
- Neo4j
- Knowledge graphs
- Agent frameworks
- Multi-agent systems
- Complex AI pipelines

The application should use normal Python processing, MongoDB and the Gemini API.

The AI workflow must simply be:

User Resource
↓
Extract readable content
↓
Store content in MongoDB
↓
User asks question
↓
FastAPI retrieves selected content
↓
FastAPI creates a prompt
↓
Gemini API
↓
Gemini generates response
↓
FastAPI returns response
↓
Save conversation to MongoDB

COLLECTION 1 — USERS
==================================================

Collection:

users

Purpose:

Store registered user accounts.

Document structure:

{
    "_id": ObjectId,
    "name": String,
    "email": String,
    "password_hash": String,
    "profile_image": String | null,
    "is_active": Boolean,
    "created_at": DateTime,
    "updated_at": DateTime
}

Rules:

- Email must be unique.
- Password must never be stored as plain text.
- Store only password_hash.
- Email should be normalized to lowercase.
