ROLE

Act as a Senior Frontend Architect, React/Next.js Developer, TypeScript Developer and UI/UX Designer.

Build a complete, modern, responsive frontend web application called:

"AI Smart Knowledge Management System"

The application is inspired by Google AI Studio and NotebookLM, but it is an original project. It should function primarily as an interactive AI knowledge chatbot and learning workspace.

The chatbot is the central feature. Users should be able to create notebooks, add learning resources, communicate with them through an AI chat interface, and generate summaries, quizzes, FAQs, flashcards and study notes.

IMPORTANT:
Build FRONTEND ONLY.

Do not implement backend logic, MongoDB, FastAPI, Gemini API calls, server authentication, or AI processing.

Use realistic mock data and mock AI responses. However, create a clean API service layer using Axios so the frontend can later connect to a FastAPI backend.
